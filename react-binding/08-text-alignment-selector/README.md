## Exercise 8

**Italiano:**

cambia l'allineamento del testo (sinistra, centro, destra) di un paragrafo selezionando l'opzione corrispondente da un gruppo di radio button

**English:**

change the text alignment (left, center, right) of a paragraph by selecting the corresponding option from a group of radio buttons

### Reasoning

**Italiano:**

```text
* INIZIO COMPONENTE AlignSelector
  * DICHIARA stato `align` inizializzato a `"text-start"`
  * RITORNA struttura JSX:
    * GRUPPO di radio button (Sinistra, Centro, Destra) che cambiano `align`
    * PARAGRAFO che applica dinamicamente la classe CSS definita in `align`
  * NOTA: Il componente è strutturato e salvato all'interno della cartella src/components/
* FINE COMPONENTE AlignSelector
```

**English:**

```text
* START COMPONENT AlignSelector
  * DECLARE state `align` initialized to `"text-start"`
  * RETURN JSX structure:
    * GROUP of radio buttons (Left, Center, Right) changing `align`
    * PARAGRAPH dynamically applying the CSS class stored in `align`
  * NOTE: The component is structured and saved inside the src/components/ folder
* END COMPONENT AlignSelector
```
