## Exercise 1

**Italiano:**

visualizza in tempo reale in un paragrafo sottostante ogni carattere digitato dall'utente in un campo di input testuale

**English:**

display in real time in a paragraph below each character typed by the user in a text input field

### Reasoning

**Italiano:**

```text
* INIZIO COMPONENTE TextEcho
  * DICHIARA stato `text` inizializzato a stringa vuota `""`
  * RITORNA struttura JSX:
    * CONTENITORE Bootstrap card
      * INPUT testuale per aggiornare `text`
      * PARAGRAFO sottostante che mostra in tempo reale il valore di `text`
  * NOTA: Il componente è strutturato e salvato all'interno della cartella src/components/
* FINE COMPONENTE TextEcho
```

**English:**

```text
* START COMPONENT TextEcho
  * DECLARE state `text` initialized to empty string `""`
  * RETURN JSX structure:
    * Bootstrap card CONTAINER
      * TEXT INPUT to update `text`
      * PARAGRAPH below displaying real-time `text` value
  * NOTE: The component is structured and saved inside the src/components/ folder
* END COMPONENT TextEcho
```
