## Exercise 4

**Italiano:**

aggiorna il contenuto di un tag <h1> con il testo inserito dall'utente in una casella di input, sostituendo il valore precedente ad ogni modifica

**English:**

update the content of an <h1> tag with the text entered by the user in an input box, replacing the previous value on every change

### Reasoning

**Italiano:**

```text
* INIZIO COMPONENTE H1Update
  * DICHIARA stato `title` inizializzato a `""`
  * RITORNA struttura JSX:
    * ELEMENTO `<h1>` dinamico che visualizza `title`
    * INPUT testuale per aggiornare `title` in tempo reale
  * NOTA: Il componente è strutturato e salvato all'interno della cartella src/components/
* FINE COMPONENTE H1Update
```

**English:**

```text
* START COMPONENT H1Update
  * DECLARE state `title` initialized to `""`
  * RETURN JSX structure:
    * DYNAMIC `<h1>` element displaying `title`
    * TEXT INPUT to update `title` in real time
  * NOTE: The component is structured and saved inside the src/components/ folder
* END COMPONENT H1Update
```
