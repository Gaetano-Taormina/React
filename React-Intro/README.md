# React-Intro & Fundamental Concepts

**Italiano:**
Raccolta completa dei 10 esercizi introduttivi sulla sintassi **JSX**, il rendering condizionale, il mapping di array (`.map()`, `.filter()`, `.sort()`) e la rappresentazione di oggetti in React, arricchiti con interfaccia moderna tramite **Bootstrap 5**.

> [!NOTE]
> **Aggiornamento Nomenclatura:** Tutte le cartelle degli esercizi sono state rinominate con descrittori funzionali in inglese (es. `01-image-display`, `05-color-palette-generator`) per una migliore organizzazione e chiarezza architetturale nella repository.

**English:**
Comprehensive collection of 10 introductory exercises covering **JSX** syntax, conditional rendering, array mapping (`.map()`, `.filter()`, `.sort()`), and object representation in React, styled with a modern UI using **Bootstrap 5**.

> [!NOTE]
> **Naming Update:** All exercise directories have been renamed with English functional descriptors (e.g., `01-image-display`, `05-color-palette-generator`) to improve repository organization and architectural clarity.

## Come eseguire i progetti / How to Run Locally

**Italiano:**
Per avviare qualsiasi esercizio:

1. Entra nella cartella desiderata (es. `cd 05-color-palette-generator`)
2. Installa le dipendenze con `npm install` (oppure `pnpm install`)
3. Avvia il server di sviluppo con `npm run dev` (oppure `pnpm run dev`)

**English:**
To run any exercise locally:

1. Navigate to the desired folder (e.g., `cd 05-color-palette-generator`)
2. Install dependencies with `npm install` (or `pnpm install`)
3. Start the development server with `npm run dev` (or `pnpm run dev`)
